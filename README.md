# VirtuBox Data Analyst Assessment

This repository contains my completed Data Analyst assessment for VirtuBox.

## Project Overview

The assessment focuses on data analysis, data cleaning, business insights, and dashboard development using the provided sales transaction dataset.

## Deliverables

### 1. Data Analysis
- Data validation and quality checks
- Data cleaning and preparation
- Business-focused analysis
- Key findings and insights

### 2. Executive Dashboard
An interactive **Sales Performance Dashboard** was created using Looker Studio.

The dashboard includes:

- Total Revenue
- Total Orders
- Unique Customers
- Monthly Revenue Trend
- Revenue by Country
- Top 10 Products by Revenue
